如何更新网站内容？

① 添加一节新课：打开 index.html，搜索定位到 ★★★ 新课程粘贴在这一行的上方 ★★★，复制一节模板粘贴到上方，改内容保存即可（新课会显示在列表最顶部）：

{
  id: 11,
  date: "2026-09-19",
  title: "第十一课：标题",
  subtitle: "Mike 老师 · 口语实战",
  intro: "本课一句话总结。",
  sections: [
    { h: "一、核心句型", type: "list", items: [
      "<span class='en'>English sentence.</span> 中文。" ] },
    { h: "二、中英对照", type: "table", head: ["中文","英文"], rows: [
      ["中文句子","<span class='en'>English sentence.</span>"] ] },
    { h: "课后作业", type: "homework", text: "复述并录音。" }
  ]
}

板块类型说明：list 要点列表（英文放 <span class='en'> 里会自动出现 🔊 按钮）／table 中英对照表／dialog 对话／tip 老师提醒／homework 作业。

② 添加单词：在 WORDS 数据区同样格式加一行：

{ w:"browse", p:"/braʊz/", m:"v. 浏览", e:"Browse Safari and you will see more." }

③ 想用真人录音/mp3？把 mp3 文件放在网站文件夹的 audio/ 里，然后在数据里加 audio:"audio/xxx.mp3"，网站会优先播放 mp3，没有就自动用内置语音。
